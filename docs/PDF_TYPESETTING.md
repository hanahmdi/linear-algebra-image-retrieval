# Academic PDF typesetting

The academic report PDF is typeset with XeLaTeX using TeX Gyre Termes (serif text) and STIX Math (mathematical notation). The corresponding editable GitHub Markdown remains at `docs/ACADEMIC_REPORT.md`.

To reproduce the PDF locally, convert GitHub `math` fences into standard LaTeX display math, then run Pandoc with XeLaTeX and the equivalent font/template options.

The PDF and Markdown describe the same project research and experiments. No new empirical accuracy values were introduced in this typography revision.
